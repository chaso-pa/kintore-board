筋トレ掲示板（Kintore Board）のプライバシーポリシーを改定してください。
対象は `kintore-board` の MDX です（公開 URL: https://app.chaso-pa.com/privacy-policies/kintore-board ）。

リポジトリの `docs/` にある手順に従い、ブランチを切るところから PR 作成まで進めてください。
**日本語と英語の両方**を同じ内容で直してください。

## 改定の理由

前回の作成以降、アプリに次の2つの機能が入りました。現行のポリシーは「どちらも無い」と
書いているので、このままでは**実態と食い違っています**。

1. **アカウント削除（退会）**: マイページからアプリ内で削除できるようになった
2. **ユーザーのブロック**: 投稿から投稿者をブロックできるようになった

また、Google Play のアカウント削除要件のため、ポリシー内のアカウント削除の節を
**アプリ外からの削除依頼先**として Play Console に登録します（下の「アンカー」参照）。

以下は、アプリのリポジトリの実装を確認して裏を取った事実です。
**ここに書いていないことは書かないでください。**

## 事実1: アカウント削除

マイページ →「アカウントを削除」→ 説明画面 → 確認 → 削除。取り消しはできません。
削除はサーバー側で一括（1トランザクション）で行われます。

| データ | 扱い |
| --- | --- |
| トレーニング記録 | **消去**（物理削除） |
| 保存したジム・保存したスレッド | **消去** |
| ブロックの記録（自分がした分・自分がされた分の両方） | **消去** |
| 自分の投稿（スレッド・レス） | **非表示**。本人による投稿削除と同じ論理削除で、サーバーには残る |
| 登録したジム・マシン・写真 | **保持**。他の利用者と共有する設備情報として残る |
| ジム情報の修正提案、自分が送った通報 | **保持** |
| アカウント（users の行） | 状態を「削除済み」にし、**端末の識別子（UUID）を上書きして端末との紐付けを消す**。権限も一般に戻す。行そのものは、保持するジム情報等が参照しているため残る |

補足:

- 削除後、アプリは初回起動と同じ状態に戻ります。利用規約に同意すると、**新しい**匿名
  アカウントが作られます。削除したアカウントとは紐づきません。
- 削除済みアカウントの認証トークンは使えなくなります。
- 端末内だけのデータ（カスタム種目・カスタム部位・非表示プリセット）は、アカウント削除では
  消えません。アプリの削除で消えます（現行 2-3 / 7-5 のとおり）。
- 「保持」としたものは、**削除済みアカウントに紐づいたまま**です。運営はどの（削除済み）
  アカウントが登録したかを内部的に判別できますが、そのアカウントは端末とも個人とも
  結びついていません。**「完全に匿名化される」「誰のものか分からなくなる」とは書かないでください。**
- 利用停止（BAN）されたアカウントはアプリ内から削除できません（サーバーが拒否します）。
  メールでの依頼で対応します。

## 事実2: ブロック

- 各投稿のボタンから、その**投稿者**をブロックできます。アプリには相手の利用者IDは
  渡りません（投稿IDで依頼し、サーバー側で投稿者を特定します）。
- ブロックすると、**双方向**に互いの投稿・スレッドが表示されなくなります
  （ブロックした側からも、された側からも見えない）。
- **ブロックされた側には通知されません。**
- ブロック時に保存されるもの: ブロックしたアカウントのID、ブロックされたアカウントのID、
  **きっかけになった投稿の冒頭（最大40文字）**、日時。冒頭は解除画面で「どの投稿で
  ブロックしたか」を示すためだけに使います。
- **ブロックすると同時に、その投稿についての通報が運営に1件送られます**（理由「ブロック」）。
  運営が問題の投稿を把握するためです。
- マイページ →「ブロックしたユーザー」から一覧の確認と解除ができます。
- アカウント削除時には、した分・された分ともに消去されます。

## 書いてはいけないこと

1. **アカウントを削除するとすべてのデータが消える**（投稿は非表示で残り、ジム・マシン・写真・
   修正提案・通報は保持されます）
2. **保持されたデータは完全に匿名化される / 誰のものか分からなくなる**（削除済みアカウントに
   紐づいたまま残ります）
3. **削除したアカウントを復元できる**（できません）
4. **ブロックしたことが相手に通知される**（通知されません）
5. **ブロックは一方向**（双方向です）
6. **NGワードフィルタや自動検知がある**（今も未実装です）
7. **利用者IDを使って本人確認する**（利用者は自分のIDを知る手段がありません）

## 書く前に確認してほしいこと

**書き始める前に私に質問してください。** 勝手に埋めないでください。

1. **保持期間**。非表示になった投稿と、保持するジム・マシン・写真・修正提案・通報を
   いつまで保持するか。現時点で自動消去の仕組みはありません。
   「無期限に保持し、申し出があれば個別に消去する」と書くのか、期限を決めるのか。
2. メールでの削除依頼に何日以内に対応するか、目安を書くか。
3. 改定の告知方法（現行 12 章「重要な変更は本アプリまたは本ページ上で通知」をどう果たすか）。
