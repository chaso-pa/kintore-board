# Play Console 入力シート

Play Console の画面に出てくる順に、入力する値を並べたもの。上から順に進めれば、内部テストへのアップロードまで終わる。
理由や背景は [`google-play-submission.md`](./google-play-submission.md) の §4〜§6 を参照。

---

## 0. 始める前に

| 確認 | 状態 |
| --- | --- |
| アップロードする AAB | `expo/android/app/build/outputs/bundle/release/app-release.aab`（versionCode 1 / 1.1.0、アップロード鍵で署名済み） |
| グラフィック素材 | `docs/screen_shots/play/` |
| プライバシーポリシーにアカウント削除の節（`#account-deletion`）がある | **要確認**。データセーフティで削除依頼の URL を聞かれる。未反映なら [`privacy-policy-update-prompt.md`](./privacy-policy-update-prompt.md) で先に改定 |

## 2. アプリのコンテンツ（ポリシー → アプリのコンテンツ）

ダッシュボードの「アプリのセットアップ」から順に開く。

### プライバシー ポリシー

```
https://app.chaso-pa.com/privacy-policies/kintore-board
```

### アプリのアクセス権

- 「**すべての機能が特別なアクセス権なしで利用可能**」を選ぶ
- 補足の欄があれば:

```
ログインは不要です。初回起動時に利用規約への同意画面が表示され、「同意して始める」をタップすると匿名アカウントが自動的に作成されます。
```

### 広告

- 「**いいえ、広告は含まれていません**」

### コンテンツのレーティング

- メールアドレス: `kintore-board.contact@chaso-pa.com`
- カテゴリ: ソーシャル / コミュニケーション / ユーザー作成コンテンツを扱うもの
- 回答:

| 質問 | 回答 |
| --- | --- |
| ユーザー同士がやり取り・コンテンツを共有できるか | **はい** |
| ユーザーの現在地を他のユーザーと共有するか | いいえ（共有されるのはジムの位置だけ） |
| デジタル商品の購入 | いいえ |
| 暴力・性的表現・薬物・ギャンブル・不適切な言葉 | すべて いいえ |

### ターゲット ユーザー

- 対象年齢: **18歳以上のみ**
- 子どもの関心を意図せず引く可能性: いいえ

### ニュースアプリ / 政府機関のアプリ / 金融機能

- すべて「いいえ / 該当なし」

### 健康アプリ

- 「アクティビティとフィットネス」（トレーニング記録）だけにチェック

### データ セーフティ

**全体の質問**

| 質問 | 回答 |
| --- | --- |
| 必須のユーザーデータを収集・共有するか | はい |
| 送信時にすべて暗号化されているか | はい |
| アカウントの作成方法 | 「その他」。説明に「初回起動時に端末ごとの匿名アカウントを自動作成（氏名・メールアドレス等の登録なし）」 |
| アカウント削除の URL | `https://app.chaso-pa.com/privacy-policies/kintore-board#account-deletion` |
| データの削除をリクエストできるか | はい |

**収集するデータの種類**（「共有」はすべて**なし**）

| 区分 → 種類 | 必須/任意 | 一時的な処理のみ | 目的 |
| --- | --- | --- | --- |
| 位置情報 → おおよその位置情報 / 正確な位置情報 | 任意 | **はい**（検索に使うだけで保存しない） | アプリの機能 |
| 写真と動画 → 写真 | 任意 | いいえ | アプリの機能 |
| アプリのアクティビティ → その他のユーザー作成コンテンツ（投稿・ジム/マシン情報） | 任意 | いいえ | アプリの機能 |
| アプリのアクティビティ → アプリの操作（保存したジム/スレ、「役に立った」） | 任意 | いいえ | アプリの機能 |
| 健康とフィットネス → フィットネス情報（トレーニング記録） | 任意 | いいえ | アプリの機能 |
| デバイスまたはその他の ID（端末で生成した匿名 ID） | 必須 | いいえ | アプリの機能、不正行為防止・セキュリティ・コンプライアンス |

収集しないもの: 氏名、メールアドレス、電話番号、連絡先、広告 ID、クラッシュログ、診断情報。

## 4. メインのストア掲載情報

### アプリ名（30文字）

```
筋トレ掲示板
```

### 簡単な説明（80文字、現在41文字）

```
マシン単位で語れる筋トレ匿名掲示板。ジムの設備・マシンDBとトレーニング記録つき。
```

### 詳しい説明（4000文字、現在1001文字）

```
筋トレを拗らせた人のための、匿名掲示板とジム設備データベースです。

「このラットプルは軌道が自然」「ここのハックは深く入れる」「このスミスは角度が好みじゃない」
——周りに話せる相手がいない話を、同じ熱量の人とする場所を目指しています。

回数とセット数を並べるだけの記録アプリでも、流れていくSNSでもありません。


■ マシン単位で語れる掲示板

全体・カテゴリ別・ジム別に加えて、マシン1台ごとにスレッドが立ちます。
BIG3、胸、背中、脚、肩、腕、サプリ、食事、減量、増量、マシン沼、筋トレあるある。

投稿はすべて匿名表示。同じスレッド内では同じIDが保たれるので会話は追えますが、
スレッドをまたぐと同一人物だとは分かりにくくなります。


■ ユーザー投稿型のジムDB

Google マップの口コミでは分からない、設備そのものの情報を集めます。

・ビジター料金 / 月額料金 / ビジター利用可否
・マシンラインナップ
・フリーウェイト設備、ダンベル最大重量
・写真
・地図から近いジムを探す

情報は運営が用意したものではなく、ユーザーが投稿したものです。
新規登録された内容は公開前に確認されます。


■ マシンDB

メーカー、対象部位、設置ジムを登録できます。
1台のマシンが複数のジムに紐づくので、「あのメーカーのあれ、どこに置いてある?」が引けます。


■ トレーニング記録

掲示板を続ける理由としての、最低限の記録機能。

・保存ボタンはありません。入力した内容は自動で保存されます
・種目ごとの推定1RM(Brzycki式)と自己ベスト更新の表示
・種目別の推移
・カレンダーで実施日を一覧
・プリセット49種目に加えて、種目も部位も自分で追加できます
・補助ありのセットを区別して記録できます
・その日の記録を1枚の画像にして共有できます


■ 入れていない機能について

意図的に作っていないものがあります。

・混雑状況
・客層レビュー
・スタッフの評価
・現実での出会いやマッチング

設備の話をする場所であって、人の話をする場所にはしないためです。

■ 安心して使うために

・不適切な投稿やジム情報は、各投稿のボタンから通報できます
・迷惑な投稿者はブロックできます（相手には通知されません）
・アカウントはマイページからいつでも削除できます
```

## 5. 内部テスト（テストとリリース → テスト → 内部テスト）

1. **テスター** タブ → メールリストを作成（まずは自分の Google アカウントだけで可）
2. **新しいリリースを作成**
   - 初回は **Play App Signing** の確認が出る →「Google が生成した鍵を使用」のまま続行
   - App Bundle に `app-release.aab` をアップロード
   - リリース名: 自動入力（`1 (1.1.0)`）のままで可
   - リリースノート:

```
<ja-JP>
初回テスト版です。
</ja-JP>
```

3. 保存 → 確認 → **内部テストとして公開**
4. テスター タブの「ウェブで参加」リンクから参加し、Play ストア経由でインストール

---

## 6. アップロード後にやること

1. **テストとリリース → 設定 → アプリの完全性 → アプリ署名** で「アプリ署名鍵の証明書」の **SHA-1** をコピー
2. Google Cloud Console の Maps API キーに、パッケージ名 `com.chasopa.kintoreboard` + この SHA-1 を追加
3. Play から入れたアプリで **地図が表示される** ことを確認（ここで出なければ 2 の漏れ）
4. クローズドテスト（12人 × 14日）の準備へ（`google-play-submission.md` §6-2）
